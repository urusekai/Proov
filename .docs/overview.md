# Proov Overview

## 설명
GitHub PR을 바탕으로 AI가 코드 이해도 문제를 내고, 답하면서 실력을 증명하는 개발 학습 플랫폼.

## 문제의식
AI가 코드를 작성하는 시대에는 직접 코드를 짜는 능력뿐 아니라, 타인이나 AI가 작성한 코드의 의미를 이해하고 검증하는 능력이 중요하다.

## 차별점
백준/프로그래머스는 가상의 알고리즘 문제 중심이다. Proov는 실제 GitHub PR diff를 기반으로 코드 독해력과 PR 이해력을 훈련한다.

## 타깃
- 취준생
- 주니어 개발자
- 실무 코드 읽기 경험이 부족한 개발자
- 코드 리뷰 역량을 키우고 싶은 개발자

## 핵심 사용자 흐름
### 비로그인
1. `/problem-sets`에서 공개 문제 목록 탐색 (문항 단위)
2. 문제 1개 풀이
3. 정답/해설/관련 파일과 원본 PR 확인
4. 같은 PR의 다른 문제 이어풀기
5. 결과 저장이 필요하면 로그인 유도

### 로그인 사용자
1. PR URL 입력 (`/problem-sets/new`)
2. PR 분석과 문제 생성 대기
3. AI가 diff 근거로 1~3문항 생성
4. 생성 완료 후 `/my-problems`(내가 만든 문제)로 이동
5. 문항 선택 후 풀이
6. 정답/해설/관련 파일과 원본 PR 확인
7. 같은 PR의 다른 문제 이어풀기
8. 풀이 기록 저장/조회 (`/history`)
9. 불필요한 문제 세트는 `/my-problems`에서 삭제
