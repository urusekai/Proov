1. 프로젝트 제목

Proov - GitHub PR 기반 코드 이해도 검증 에듀테크 플랫폼


================================================================

2. 프로젝트 배경

AI가 코드를 자동으로 작성하는 시대가 도래하면서, 개발자에게
요구되는 역량이 변화하고 있습니다. 단순히 코드를 작성하는
능력뿐 아니라, 타인 혹은 AI가 작성한 코드의 의미를 정확히
이해하고 검증하는 능력이 점점 더 중요해지고 있습니다.

기존의 코딩 테스트 플랫폼(백준, 프로그래머스 등)은 알고리즘
문제 풀이 중심으로, 실제 업무 환경에서 마주하는 코드 독해·
PR 리뷰·변경 의도 파악 등의 역량을 훈련하기에는 한계가
있습니다. 취업 준비생과 주니어 개발자들은 실무 코드를 읽고
이해하는 경험이 부족한 상태로 현장에 투입되는 경우가 많습니다.

Proov는 이러한 문제를 해결하기 위해, 실제 GitHub Pull Request의
diff를 기반으로 AI가 코드 이해도 문제를 생성하고, 사용자가
이를 풀며 실력을 증명할 수 있는 학습 환경을 제공합니다.


================================================================

3. 프로젝트 목표

- 실제 오픈소스 PR diff를 학습 콘텐츠로 활용하여, 실무 코드
  독해 역량을 체계적으로 훈련할 수 있는 플랫폼을 제공한다.

- AI(GPT-5.4)를 활용해 PR 변경 내용을 근거로 한 객관식 문제를
  자동 생성함으로써, 양질의 학습 문제를 지속적으로 공급한다.

- 사용자가 공개 문제를 풀거나, 원하는 GitHub PR URL을 직접
  입력해 맞춤형 문제를 생성·학습할 수 있도록 한다.

- 풀이 기록과 유형별 정답률을 제공하여, 자신의 강점과 약점을
  파악하고 성장 방향을 스스로 설계할 수 있게 한다.


================================================================

4. 기능 및 서비스

[ 비로그인 사용자 ]
  - 사이트에서 큐레이션한 공개 문제 목록 열람 및 풀이
  - 채점 결과 및 해설, 관련 파일 확인
  - 같은 PR에서 나온 다른 문항 이어풀기

[ 로그인 사용자 ]
  - 공개 GitHub PR URL 직접 입력 후 AI 문제 자동 생성
  - 생성된 문제를 내 문제 목록에서 관리 및 삭제
  - 풀이 결과 자동 저장 및 기록 목록·상세 조회
  - 마이페이지에서 프로필 수정, 비밀번호 변경, 회원탈퇴

[ AI 문제 생성 ]
  - PR diff를 분석하여 객관식 3문항 자동 생성 (GPT-5.4)
  - 문항별 난이도(쉬움/보통/어려움) 및 유형 태그 자동 분류
    예) Code Behavior, Data Flow, State Change,
        Error Handling, API Contract 등
  - 변경 파일 최대 8개, 전체 diff 최대 12,000자 등
    품질 보장을 위한 제한 정책 적용

[ 문제 탐색 및 필터링 ]
  - 언어 / 프레임워크 / 난이도 기준 필터
  - 최신순 · 난이도순 정렬
  - 문항 제목, 관련 파일명, 저장소명, PR 메타데이터 카드 표시

[ 학습 통계 ]
  - 푼 문항 수, 강한 유형 / 약한 유형, 연속 풀이일 요약
  - 난이도별 풀이 현황, 유형별 정답률 제공
